Gloamdeep needs a local web server

Browsers block JavaScript modules on file:// pages. Start a server in this folder and open the address it prints:

python -m http.server 8000

…then visit http://localhost:8000. On Windows you can also double-click start.bat.

Deutsch: Bitte über einen lokalen Server starten (z. B. start.bat oder python -m http.server 8000) und dann http://localhost:8000 öffnen.

Oder direkt online spielen: dawasteh.github.io/Browser-Games-Collection/gloamdeep/

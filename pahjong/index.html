Wann ist ein Stein frei?

Kein Stein einer höheren Ebene darf seine Fläche überdecken. Zusätzlich muss links oder rechts die gesamte lange Seite offen sein. Das Spiel berechnet genau dieselben Halbstein-Flächen, die du siehst.

Welche Steine passen?

Kreise, Bambus, Zeichen, Winde und Drachen brauchen dasselbe Motiv und denselben Wert. Die vier unterschiedlichen Blumen passen untereinander; ebenso die vier Jahreszeiten.

Was bedeutet „lösbar“?

Jeder Deal besitzt beim Austeilen einen vollständig geprüften Entfernungsweg. Ein anderer legaler Zug kann trotzdem in eine Sackgasse führen. „Mischen“ verteilt nur die übrigen Motive in eine erneut geprüfte Fortsetzung.

Tastatur

Tab betritt das Brett; Pfeiltasten wechseln räumlich zwischen freien Steinen. Enter/Leertaste wählt. H Hinweis, M Mischen, U Rückgängig, N neues Spiel, Esc Auswahl aufheben.
